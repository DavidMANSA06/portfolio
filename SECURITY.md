# Politique de sécurité

## Signaler une vulnérabilité

Si vous découvrez une faille de sécurité dans ce site ou dans ce dépôt, merci de **ne pas ouvrir d'issue publique**.

Utilisez plutôt le signalement privé de GitHub : onglet **Security** → **Report a vulnerability**.
Vous pouvez aussi écrire à l'adresse indiquée sur le site.

Je m'engage à accuser réception sous 7 jours et à vous tenir informé(e) de la correction.

## Périmètre

- Le code de ce dépôt et le site déployé à partir de lui.
- Les dépendances tierces sont suivies automatiquement ; une vulnérabilité connue d'un paquet peut aussi être signalée ici.
